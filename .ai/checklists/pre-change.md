# Checklist — Pre-change

- [ ] A tarefa atual foi compreendida sem reutilizar permissões antigas.
- [ ] O tipo de tarefa foi classificado.
- [ ] Os arquivos fonte necessários foram lidos.
- [ ] A API pública potencialmente afetada foi identificada.
- [ ] Os testes relacionados foram identificados.
- [ ] A documentação do domínio foi lida.
- [ ] O comportamento a preservar foi registrado.
- [ ] Alterações autorizadas e proibidas estão claras.
- [ ] As validações possíveis foram definidas.
- [ ] O conjunto esperado de arquivos da entrega foi delimitado.
